# 桌面重写版 Review（2026-10-31）

范围：Tauri sidecar 启停与打包路径、本地 HTTP 鉴权、RSS 刷新/解析、全文提取、图片下载、阅读器异步状态、SQLite 写入和现有测试。属于核心链路 review，未逐站验证全部 RSS 目录，未在 Windows/Linux 做运行验收。

## 已修复

- **高：macOS 桌面启动不继承终端代理，Node fetch 也不会自动读取系统代理。** 本机 Hacker News 报 `fetch failed`；新增统一网络层，读取 `scutil --proxy` 中启用的 HTTP/HTTPS 配置，显式环境变量优先，支持 NO_PROXY（包括 `*`），本机回环直连。RSS、正文、图片、AI 全部接入；30 秒缓存避免每个图片请求起系统子进程，代理切换时让旧连接完成在途请求。
- **高：本地入口提供令牌，未限制 Host。** 加上回环 Host 白名单防止 DNS rebinding；含令牌入口禁用缓存，图片签名密钥改为每次启动随机值，鉴权豁免限定 `/api/image` 精确路径。
- **中：抓取失败原因丢失。** HTTP 拒绝、网络失败、读取超时和非网页响应明确返回上游错误并记录日志；仅提取结果为空时提示无法提取，RSS 原文仍保留。
- **中：下载不限制实际体积。** RSS/网页限制解压后 8 MiB，图片限制 12 MiB；按流累计，超限取消，不依赖可能缺失或错误的 Content-Length。图片拒绝响应及时取消 body。
- **中：正文懒加载图片与相对链接丢失。** 提取前恢复常见 data-src/data-original/data-lazy-src/data-srcset，按跳转后的 URL 和页面 base 解析普通链接及图片地址，仍经过 HTML 净化，库内保存原始图片 URL。
- **中：切文章/清空选择/切视图时旧响应污染状态。** 取消选择和换视图也递增请求序号；全文 spinner 跟随当前文章，在途 A 请求结束不会清掉 B 的抓取状态。
- **中：XML 解析失败未写订阅抓取状态。** 现在保存失败原因和尝试时间，避免页面仍显示旧成功状态、调度器反复选中同一坏源。

## 后续范围

- 系统代理自动发现目前针对 macOS HTTP/HTTPS；PAC、纯 SOCKS、CIDR/<local> 系统例外规则，以及 Windows/Linux 原生系统代理发现尚未实现。可使用 HTTP/混合代理端口、HTTP_PROXY/HTTPS_PROXY 和域名 NO_PROXY。
- Readability 不执行源站 JavaScript，无法保证登录墙、Cloudflare 挑战及纯客户端渲染站点提取；失败保留 RSS 内容。没有绕过源站验证或关闭 TLS 校验。
- AI 网络路径共用代理，现有 SSE 回归通过；未使用用户真实 API Key 发起付费模型验收。
- RSS 目录为延迟加载的大资源，Vite 仍有 chunk 大小提示，不影响首屏或本次抓取修复。

代理 API 参照 [Undici EnvHttpProxyAgent](https://github.com/nodejs/undici/blob/main/docs/docs/api/EnvHttpProxyAgent.md)。
